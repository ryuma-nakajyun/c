# C Language Training
C言語の学習および検証を行うためのリポジトリです。

## 学習方針
単にプログラムを動作させることを目的とせず、
- なぜその設計を採用するのか
- メモリやリソースをどのように管理するのか
- 保守性・可読性をどのように確保するのか　　
を考えながら学習・検証を行っています。

## 目的
- C言語の基本文法の習得
- コンパイルの仕組みの理解
- Makefileの学習
- メモリ管理の理解
- Linux環境での開発経験の習得

## ディレクトリ構成
```text
myproject/
```
学習用ソースコードおよび検証コードを管理しています。

## 学習内容
- 基本文法
- 変数・型
- 関数
- ポインタ
- 配列
- 構造体
- ファイル入出力
- メモリ管理
- Makefile
- デバッグ

## ビルド
```bash
make
```

## 実行
```bash
./main
```
※ 実行ファイル名はプロジェクト構成に応じて変更してください。

## クリーン
```bash
make clean
```
